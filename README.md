# Supply Chain & Inventory Risk Analytics

## Project Overview
This project analyzes sales, inventory levels, supplier lead times, and reorder risks to support better inventory planning.

## Tools Used
- Excel Power Query — Data cleaning
- SQL Server — Data analysis
- Power BI — Interactive dashboard

## Key Insights
- SKU_18 had the highest units sold.
- 4,787 records were below the reorder point.
- March had the highest monthly sales; September had the lowest.
- SUP_4 had the longest average lead time at 8.64 days.

## Recommendations
- Monitor low-stock products regularly.
- Reorder products on time.
- Plan inventory based on monthly demand.
- Review suppliers with longer delivery times.

## Data Limitation
The stockout flag contained only zero values, so stockout performance could not be reliably measured.

## Project Files
- `Dataset/` — Raw and cleaned data
- `SQL/` — SQL queries
- `PowerBI/` — Power BI dashboard
- `Screenshots/` — Dashboard image

## Conclusion
This project demonstrates data cleaning, SQL analysis, and Power BI dashboard development for inventory risk management.
